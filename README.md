# 🌈 Belajar Ceria

> 🎮 Game edukasi interaktif untuk anak — belajar sambil bermain!

**Belajar Ceria** adalah game edukasi berbasis HTML, CSS, dan JavaScript yang dirancang agar anak dapat belajar dengan cara yang sederhana, menyenangkan, dan interaktif langsung dari HP.

## ✨ Fitur Saat Ini

### 🔢 Angka 1–10
- Mengenal angka 1 sampai 10
- Menghitung benda
- Memilih jawaban
- Sistem skor ⭐
- Sistem kesempatan ❤️
- Suara bahasa Indonesia 🔊
- Animasi jawaban benar/salah
- Layar kemenangan 🏆

### 🔤 Huruf A–Z
- Mengenal huruf A sampai Z
- Contoh kata untuk setiap huruf
- Gambar/emoji pendukung
- Pilihan jawaban interaktif
- Sistem skor dan kesempatan
- Pembacaan suara bahasa Indonesia

### 📱 Dirancang untuk HP
- Tampilan responsif
- Tombol besar dan mudah disentuh
- Tidak membutuhkan aplikasi tambahan
- Dapat dijalankan langsung melalui browser

## 🚀 Cara Menjalankan

### Cara 1 — Langsung di HP
1. Download `belajar-ceria.html`.
2. Buka file menggunakan browser.
3. Game langsung dapat dimainkan.

### Cara 2 — GitHub Pages
1. Buat repository baru di GitHub.
2. Upload file `belajar-ceria.html`.
3. Rename menjadi `index.html`.
4. Aktifkan **GitHub Pages**.
5. Buka alamat Pages yang diberikan GitHub.

## 📁 Struktur Project


## 🌟 Rencana Pengembangan

Belajar Ceria akan dikembangkan menjadi platform game edukasi anak dengan:

- 🏅 Sistem level
- ⭐ Koleksi bintang dan hadiah
- 👤 Profil pemain
- 🐰 Karakter/maskot
- 🎵 Musik dan efek suara
- 🎨 Game warna
- 🐯 Game mengenal hewan
- 🍎 Game mengenal buah
- 🧩 Puzzle edukasi
- ✏️ Latihan menulis
- 🧠 Kuis pengetahuan
- 📊 Rekap perkembangan belajar
- 👨‍👩‍👧 Mode orang tua
- 🏆 Pencapaian/badge

## 💡 Konsep Pembelajaran

Game dibuat dengan prinsip:

**Lihat → Dengarkan → Pilih → Dapatkan Bintang → Lanjut Level**

Tujuannya adalah membuat proses belajar terasa seperti bermain sehingga anak lebih tertarik untuk mencoba berulang kali.

## 🔊 Catatan Suara

Fitur suara menggunakan kemampuan text-to-speech yang tersedia pada browser/perangkat.

Karena menggunakan suara bawaan perangkat, hasil suara dapat berbeda antara Android, Chrome, dan perangkat lainnya.

## 🌐 Bisa Dikembangkan Menjadi PWA

Project ini dapat dikembangkan menjadi **Progressive Web App (PWA)** sehingga pengguna dapat:

- Menambahkan game ke layar utama HP
- Membuka game seperti aplikasi
- Menggunakan ikon aplikasi sendiri
- Mendukung penggunaan offline dengan service worker

## 📄 Lisensi

Project ini dapat digunakan sebagai dasar pengembangan aplikasi edukasi.

Lisensi dan ketentuan penggunaan dapat ditentukan kemudian apabila project akan dipublikasikan atau dikomersialkan.
